主な実績

決済の二重処理を防ぐ設計

クレジットカード決済の3Dセキュア連携で、受付番号による一意管理とコールバック処理を実装しました。決済が重複した場合は検知してキャンセルし、決済失敗時はトランザクション制御で在庫を元に戻します。

PHP / Laravel / MySQL / トランザクション

実行計画に基づくクエリ改善

EXPLAINのtype（ALL→ref）やスキャン行数を確認し、複合インデックスの設計、JOIN順の再設計、N+1問題の解消を行いました。大量データの一覧はページングで負荷を抑えています。

MySQL / EXPLAIN / Composite Index

既存資産と整合するDB設計

第2・第3正規形を意識したテーブル設計を担当しました。既存のSJISテーブルと文字コードや型が違うとJOINでインデックスが効かなくなるため、結合先に合わせて設計しています。

RDB設計 / 正規化 / 文字コード

制作物

Team Task Management API開発中

チームのタスク管理向けREST APIです。ワークスペース、プロジェクト、タスク、メンバー権限、変更履歴（監査ログ）を扱います。

技術と選定理由
NestJS / TypeScript（モジュール単位で構成し、型で安全に開発するため）、PostgreSQL / Prisma（リレーショナルデータ、トランザクション、マイグレーションを管理するため）、Redis / BullMQ（通知メールを非同期で処理し、失敗時に再試行するため）、JWT（認証）、Docker Compose（開発環境の統一）。
工夫した点
同じタスクを複数人が同時に更新すると上書きが起きる問題に対し、versionによる楽観的ロックを実装しました。更新はversionを条件に行い、古い場合は409 Conflictを返します。タスクの更新と監査ログの保存は、同一トランザクションで実行しています。
実装状況
認証、ワークスペース・プロジェクト・タスクのCRUD、コメント、添付アップロード、進捗の集計、通知メールを実装済みです。添付のダウンロードと削除は未実装です。

Beto Sandoichi開発中

バインミー（ベトナム風サンドイッチ）のオンライン注文アプリです。顧客は注文と代金引換での支払いができ、管理者は商品、在庫、注文、ポイントを管理できます。

工夫した点
注文、在庫、ポイントの整合性を保つため、注文処理の流れを設計し、業務ロジックをバックエンドのサービス層にまとめています。
